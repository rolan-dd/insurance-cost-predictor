# Medical Insurance Cost Predictor (Streamlit)

## How to test
1. Open the deployment link.
2. Fill in every field (age, smoker status, etc.).
3. Click **Predict** to see the predicted annual medical cost.
4. Change one field (e.g. smoker: no -> yes) and predict again to see the effect.

## Files
- `app.py` - the Streamlit app
- `best_insurance_model.joblib` - best model saved by the notebook
- `requirements.txt` - packages
- the Kaggle CSV (optional, only used for input ranges)
